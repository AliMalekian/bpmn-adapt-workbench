# OMG BPMN 2.0.2 schema source

These machine-readable schemas are the normative files listed for BPMN 2.0.2
by the Object Management Group at <https://www.omg.org/spec/BPMN/>. Runtime
validation uses only these vendored copies and never retrieves schemas over the
network. Exact URLs and SHA-256 digests are recorded in `manifest.json`.
